# 主机安装与手机使用

现在有两种交付形态：

- **主机**：macOS 菜单栏 App（`.pkg` 安装包）+ 浏览器里的 Web 界面；
- **手机**：浏览器安装的 PWA（Android 是真正安装，iPhone 用 Safari 添加到主屏幕）。

不需要 App Store，也不需要 Apple 开发者账号。

## 一、安装主机端

两种方式任选：

```bash
# 方式一：安装包（推荐）
双击 dist/静静-0.2.0.pkg

# 方式二：解压 zip，把「静静.app」拖进「应用程序」
unzip dist/静静-0.2.0.zip
```

这个包没有经过 Apple 公证，第一次打开可能被 Gatekeeper 拦住：

- 右键点击「静静.app」→「打开」；
- 或者在「系统设置 → 隐私与安全性」里点「仍要打开」。

打开后：

1. 菜单栏出现「静静」；
2. Node 服务自动启动（默认端口 7777，监听局域网）；
3. 第一次运行会自动用配对链接打开浏览器；
4. 菜单里可以：打开控制台、显示/复制配对码、手机安装二维码、仅本机访问、重启、看日志、退出。

数据在 `~/Library/Application Support/Jingjing/`，配对码在同目录的 `access-key`。

> 想让它在登录后自动启动：系统设置 → 通用 → 登录项，把「静静」加进去。

## 二、手机安装（PWA）

### 1. 让手机能找到主机

推荐 Tailscale：

1. Mac 和手机都装 Tailscale，登录同一账号；
2. 菜单栏「静静」→「手机安装二维码…」，二维码里已经包含主机地址和配对码；
3. 手机相机扫码，浏览器会打开静静并自动登录。

同一 Wi-Fi 也可以，前提是主机 App 没有勾选「仅本机访问」。

### 2. 安装到桌面

- **Android Chrome**：右上角菜单 →「安装应用」/「添加到主屏幕」；
- **iPhone Safari**：分享按钮 →「添加到主屏幕」；
- **Mac / Windows Chrome**：地址栏右侧的安装图标。

装好后是一个独立窗口，图标和 App 一样。配对信息存在手机浏览器里，下次打开不用再输。

### 3. 接收消息

- **打开 App 时**：通过 SSE 实时收到任务进度和审批，任务卡会出现在对话里；
- **App 在后台/锁屏时**：PWA 本身没有可靠的系统推送，推荐配 Telegram（设置 → 通知通道），审批会发到手机，点按钮就能让主机继续。

## 三、从命令行版迁移数据

App 版的数据目录是 `~/Library/Application Support/Jingjing/`，和项目里的 `data/` 是分开的。想保留现在的任务、记忆、模型 Key 和插件配置：

```bash
# 先退出主机 App、停掉 npm start
mkdir -p "$HOME/Library/Application Support/Jingjing"
cp -R data/. "$HOME/Library/Application Support/Jingjing/"
```

再打开 App，配对码和数据都会是原来的。

## 四、配对与安全

- 所有 `/api/*` 接口都需要配对码；浏览器用 HttpOnly Cookie，脚本/外部客户端用 `Authorization: Bearer <码>`。
- 配对码在主机 App 里可以显示、复制和重新生成；重新生成会让所有设备下线。
- 手机和主机之间的 HTTP 在网络上是明文的。用 Tailscale 或可信 Wi-Fi；不要把 7777 端口映射到公网。
- 菜单里的「仅本机访问」会把监听地址切回 `127.0.0.1`，手机就连不上了。

## 五、常见问题

**手机打开是「无法连接」**：确认主机没睡眠、App 菜单显示「静静 ●」、手机和主机在同一个 Tailscale 网络；先用手机浏览器打开 `http://<主机IP>:7777/api/health`，应返回 `{"ok":true}`。

**扫码后停在登录页**：二维码里的配对码可能过期（重新生成过）。在主机菜单里重新打开二维码。

**安装按钮不出现**：用 Chrome / Edge / Safari；Firefox 对 PWA 安装支持有限。iOS 只能手动「添加到主屏幕」。

**主机的 Web 界面打不开**：菜单栏「打开控制台」会自动带上配对链接；如果浏览器提示未配对，在设置页输入配对码。

**换端口**：启动时设 `JINGJING_PORT=7788`，或用 `pkg` 安装后在 `~/Library/LaunchAgents` 里没有配置项——主机 App 目前固定 7777，改端口需要用命令行版。
