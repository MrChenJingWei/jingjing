# 企业微信智能机器人插件

这个插件通过企业微信的 WebSocket 长连接接收智能机器人的消息，把单聊消息或群里 `@机器人` 的消息交给静静判断、建任务。它和其他插件一样安装、删除。

不需要公网 IP，也不需要回调 URL；主机能主动访问企业微信即可。

## 一、企业微信后台

1. 进入企业微信管理后台 → 工作台 → 智能机器人 → 新建机器人；
2. 把机器人可见范围设好；
3. 在机器人编辑页把连接方式切换为 **API 模式 → 长连接**；
4. 在机器人详情页复制两个凭证：
   - **BotID**
   - **Secret**（长连接凭证，不是企业应用的 Secret）
5. 把机器人加进目标群，或直接在单聊里使用。

> 群聊里只有 `@机器人` 的消息会推给机器人；普通群聊内容不会推。想读全部群消息只能走屏幕捕获或企业会话存档。

## 二、安装插件

设置 → 任务来源插件 →「安装插件」，选择：

```
dist/plugins/wecom-0.1.0.zip
```

安装后插件默认停用，点进详情填配置再启用。

## 三、配置并启用

1. 填 **BotID**、**Secret**；
2. 「收到消息后在企微里回执」默认开启，会回复“收到，已建 N 个任务”；
3. 点「保存配置」，再打开启用开关；
4. 启用后静静会建立长连接，状态应显示「长连接已启动」。

连接失败会显示在卡片底部，常见原因：

- BotID/Secret 复制错；
- 机器人没有开启 API 模式；
- 主机网络无法访问 `openws.work.weixin.qq.com`；
- 机器人可见范围不包含发送者。

## 四、使用

在群里：

```
@静静 登录页点提交没反应，帮忙看下
```

静静会把这条消息转成条目：

- `externalId`：企业微信 `msgid`，重复回调不会重复建任务；
- 标题：`企微群消息 · <userid>`；
- 内容：消息正文（有引用时带上引用）；
- 元数据：chatid、chattype、userid。

然后走正常的判断：需要行动就建任务，不需要就不打扰。任务可以通过调度器派给 Claude Code，也可以在任务板里手动处理。

## 能看到静静怎么判断吗

能，但看到的是**判断摘要**，不是模型的原始思维链：

1. 收到消息先回「收到，正在看…」；
2. 判断完成后回：
   - 需要行动：`已经建了 N 个任务：- 标题：理由`
   - 不需要：`看过了，这条先不动：理由`
3. Web 端「设置 → 任务来源插件 → 企业微信 → 最近处理」会保留最近 20 条消息的标题、时间、判断结果和理由，可以直接点「看任务」；
4. 任务详情里的「判断理由」也会写进交给 Worker 的指令。

回执只表示“收到并已交给静静”，不代表代码已经修好。

## 五、限制

- 只处理**文本消息**；图片、语音、文件会忽略；
- 只接收机器人被 `@` 的群消息和发给机器人的单聊消息；
- 长连接断开后 SDK 会自动重连，重连期间消息可能延迟；
- 回复频率受企业微信限制（单会话 30 条/分钟、1000 条/小时）；
- Secret 存在本机 SQLite，界面打码，但不是加密存储；
- 插件依赖官方 `@wecom/aibot-node-sdk`，已一起打进 zip。

## 六、重新打包

插件源码在 `plugin-src/wecom/`：

```bash
cd plugin-src/wecom
npm install --omit=dev
cd ../..
zip -qr dist/plugins/wecom-0.1.0.zip wecom -x "*/node_modules/.cache/*"
```

改了 `index.js` 或 `plugin.json` 后重新打 zip，再从设置页安装/覆盖即可。
