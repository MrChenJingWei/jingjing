模型

「OpenAI 兼容接口」不只能接 DeepSeek：Kimi、GLM、通义、公司网关、中转站，以及本机 Ollama 的 /v1，只要提供 /chat/completions 都能用。演示模式不需要任何 Key，也能完整体验任务闭环。

称呼与人设

人设会注入 Router 回答和 Worker 执行的系统提示词，保存后立即生效。

记忆与成长

静静会记住聊过的事，有自己的心情，每天反思一次：把经历整理成长期记忆、更新对人的印象，也可能调整自己的人设（每次只改一点，三天最多一次）。

人设的历史

她自己改的、你改的、回退的都在这里，点「用这一版」随时回去。

执行

核心约定：Agent 跑完一轮就退出；等待拍板时进程退出，不占 CPU、不烧 token。

执行器

Worker 是无状态执行器。内置适配器之外，可以安装 Worker 插件来接入你主机上的其他 Agent / CLI。

本机能力

这台电脑上装了什么工具、能做哪类事。在下面每个 Worker 的「配置」里勾上它能用哪些，派活时静静会按能力挑人。内置的不能改；列表里没有的（比如公司内部的命令行工具），在这里加。

兜底 Worker

没有流程、分配规则，也没点名 Worker 时交给它；它不可用时自动退回最便宜的文本 Worker。外部来源（企微、邮件……）的消息也一样：选能执行命令的 Worker（比如 Claude Code），别人发来的消息也可能让它在这台电脑上动手。

分配规则

按顺序匹配，命中后覆盖 Router 的判断。手动明确指定 Worker 的任务不经过规则。

Claude Code 的工具权限由你本机的 Claude Code 配置和 macOS 账户权限决定，静静不会覆盖。Codex 同理。

流程

每个流程是一个 .md 文件：头部写触发词（when）、Worker、工作区，正文写步骤。命中流程的请求不再让模型猜，直接按流程派活。完成的任务会被总结成「候选习惯」，你确认后才生效。

读取的文件夹

每行一个文件夹，静静会读取里面（最多 3 层）的 .md 文件；请指向专门放流程文档的文件夹，不要指向整个笔记库。静静只读不改这些文件，停用只记在本机。 总会被读取，学到的习惯放在它的 learned/ 子目录。

定时任务

按时间自己跑：到点建一个任务，或者把某个来源扫一遍、按指定流程处理新条目。比如「每天早上汇总 TAPD 待办」「每天 2 点把 TAPD 里可自动修的 bug 修掉」。

自动归类

来源插件声明了能力才会出现在这里，默认全部关闭。建议先「试运行」：只在后台算归属，任务列表不变，看效果再开启。

分类

一个分类太大说明切得太浅；空的自动分类过一段时间会被回收（连带它自动积累的知识，手动记的保留）。

知识

每个分类是一个知识域：修完一张卡，静静记下关系、状态和结论；分配同一分类下的新任务时，把确认过的知识附进指令。知识只用来判断，不影响交给谁做。

工作区

任务来源只决定「发现什么」，工作区决定「在哪个目录里干活」。每个来源插件可以绑定一个工作区；没有绑定就跟随默认。工作区只决定起点，不限制 Worker 能访问哪些目录——那由 macOS 账户权限和 Worker 自身配置决定。
