配对与手机

Android：用 Chrome 打开上面的地址，输入配对码，然后在菜单里选「安装应用 / 添加到主屏幕」。iPhone 暂不提供原生包。

安装到手机 / 桌面

静静是 PWA，不需要应用商店。手机浏览器打开主机地址并配对后，用下面的方式安装；装好后是一个独立窗口的图标，和 App 一样。

AndroidChrome 右上角菜单 → 安装应用 / 添加到主屏幕
iPhone / iPadSafari 分享按钮 → 添加到主屏幕
Mac / WindowsChrome 地址栏右侧的安装图标

工作区

任务来源只决定「发现什么」，工作区决定「在哪个目录里干活」。每个来源插件可以绑定一个工作区；没有绑定就跟随默认。工作区只决定起点，不限制 Worker 能访问哪些目录——那由 macOS 账户权限和 Worker 自身配置决定。
